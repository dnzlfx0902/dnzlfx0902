## About

I'm **Christian**, a full-stack developer from San Luis Potosí, Mexico. Most of my time goes
into local AI and automation, almost always on Linux with Docker. I care about software that
runs on my own machines — and that you can read end to end.

Lately I've been building agents with memory, vision and voice, local model inference, a tool
that draws breadboard diagrams deterministically, and homelab automation.

### ⚡ [electronica-cad](https://github.com/dnzlfx0902/electronica-cad)
